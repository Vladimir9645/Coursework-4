# Coursework_4 — Django рассылка

Курсовая работа: веб‑приложение для управления email‑рассылками на Django.

## Возможности

- Управление получателями (CRUD)
- Шаблоны писем
- Создание и запуск рассылок с периодом и статусами
- Статистика рассылок (дашборд)
- Авторизация/регистрация через django-allauth

## Структура проекта

- `clients/` — управление получателями
- `mail_templates/` — шаблоны писем
- `mailings/` — рассылки, логика отправки, попытки доставки
- `stats/` — дашборд со статистикой
- `templates/` — общие и частные шаблоны
